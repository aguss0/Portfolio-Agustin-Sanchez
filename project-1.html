proyecto 01

Pokédex App

Buscá cualquier Pokémon por número o nombre y consultá su tipo, sprite oficial y estadísticas base en tiempo real usando la PokéAPI.

JavaScript Fetch API PokéAPI HTML / CSS async / await
demo en vivo

Ingresá un número o nombre para comenzar.

funcionalidades
  • Búsqueda por número de Pokédex o nombre en inglés.
  • Sprite oficial de alta resolución obtenido desde la PokéAPI.
  • Tipos del Pokémon con colores distintivos por cada tipo.
  • Barras animadas para HP, Ataque, Defensa, Sp. Ataque, Sp. Defensa y Velocidad.
  • Manejo de errores: informa si el Pokémon no existe o hay problema de red.
código destacado

pokedex.js

// Consulta la PokéAPI y normaliza la respuesta
async function fetchPokemon(query) {
  const url = `https://pokeapi.co/api/v2/pokemon/${query.toLowerCase()}`;
  const response = await fetch(url);
 
  if (!response.ok) throw new Error('Pokémon no encontrado');
 
  const data = await response.json();
 
  return {
    id:     data.id,
    name:   data.name,
    sprite: data.sprites.other['official-artwork'].front_default,
    types:  data.types.map(t => t.type.name),
    stats:  data.stats.map(s => ({
      name:  s.stat.name,
      value: s.base_stat,
    })),
  };
}
