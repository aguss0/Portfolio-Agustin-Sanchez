proyecto 02

To-Do List

Tablero de tareas estilo Kanban con tres columnas: Por hacer, En progreso y Listo. Drag & drop entre columnas, persistencia en localStorage y formulario para agregar tareas.

React Tailwind CSS localStorage Drag & Drop useState
demo en vivo
funcionalidades
  • Tres columnas: Por hacer, En progreso y Listo.
  • Formulario para agregar tareas con título y descripción.
  • Drag & drop nativo del navegador para mover tarjetas entre columnas.
  • Persistencia en localStorage: las tareas sobreviven al recargar la página.
  • Botón para eliminar cada tarea individualmente.
  • Contador de tareas por columna.
código destacado

kanban.jsx

// Persistencia: carga y guarda en localStorage
const [tasks, setTasks] = useState(() => {
  const saved = localStorage.getItem('kanban-tasks');
  return saved ? JSON.parse(saved) : initialTasks;
});
 
useEffect(() => {
  localStorage.setItem('kanban-tasks', JSON.stringify(tasks));
}, [tasks]);
 
// Mover tarea entre columnas al soltar
const handleDrop = (e, targetColumn) => {
  const taskId = e.dataTransfer.getData('taskId');
  setTasks(prev => prev.map(t =>
    t.id === taskId ? { ...t, column: targetColumn } : t
  ));
};
